# README: Running MergeSort on a SLURM Cluster

## Prerequisites
Ensure you have the following installed:
- A Linux-based system with SLURM workload manager
- GCC compiler
- Bash shell
- Python 3 with pandas and matplotlib libraries

## Compilation
Before running MergeSort, compile the C++ code:
```sh
g++ -o mergeSort mergeSort.cpp
```

## Running the MergeSort Benchmark
To submit the MergeSort job to the SLURM scheduler, use the provided script:
```sh
sbatch mergescript.sh
```
This script runs MergeSort on different input sizes and records execution times.

## Viewing Results
Once the job completes, output times will be available in the standard output file generated by SLURM. You can redirect them to a CSV file:
```sh
sbatch mergescript.sh > output.csv
```

## Plotting Results
To visualize the sorting performance, run the Python script:
```sh
python plot.py
```
This will generate a log-log plot of sorting time vs. number of elements, saved as `sorting_time_vs_elements.png`.

## Notes
- Modify `mergescript.sh` if using a different SLURM partition.
- Ensure the script has execute permissions: `chmod +x mergescript.sh`.
- Adjust memory/time limits in the SLURM script as needed.

## Troubleshooting
- If MergeSort does not execute, ensure `mergeSort` is compiled and executable (`chmod +x mergeSort`).
- If Python script fails, install dependencies with:
  ```sh
  pip install pandas matplotlib
  ```
